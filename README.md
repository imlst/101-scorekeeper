# 101 – счет игры

Локальный счетчик очков для карточной игры 101 на React, TypeScript и Vite.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

## Возможности

- новая партия для 2–5 игроков;
- ввод положительных и отрицательных очков после раздачи;
- обнуление при ровно 101 или −101 очке;
- завершение партии при значении выше 101 или ниже −101;
- история очков каждого игрока и итоговая таблица;
- автосохранение текущей партии в `localStorage`.

Данные остаются в текущем браузере и профиле. Очистка данных сайта удалит сохраненную партию.
